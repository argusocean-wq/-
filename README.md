# Taiwan Junior High School Mock Exams

台灣國中教育會考線上模擬測驗專案。

## 專案方向

- 七大科目：國文、英語、數學、社會、自然、寫作測驗、英語聽力。
- 每個適用科目提供簡單、中等、困難三個練習層級。
- 歷屆試題來源以國中教育會考官方網站為準；匯入前確認使用條款、著作權與再散布許可。
- 尚未完成來源核對的題目不得標記為已匯入或官方題目。

## 官方歷屆試題

https://cap.rcpet.edu.tw/examination.html

## 匯入進度

請查看[試題匯入進度報告](docs/import-progress.md)。目前本輪追蹤的 2025、2026 年 14 個科目項目已完成來源登記（100%），但完整題目內容匯入為 0/14（0%）；來源登記不等於題目已匯入。
