# 會考練習室｜國中線上題庫

**線上網站：** https://argusocean-wq.github.io/-/

這是一個可部署到 GitHub Pages 的純前端會考練習網站，成績與個人資料預設儲存在目前使用的瀏覽器。

## 題庫狀態
- 合併後題目紀錄：560 題（原有 500 題＋本次新增 60 題）。
- 科目：國文 112、英語 112、數學 132、社會 102、自然 102。
- 新增的 60 題為原創會考風格練習題，含解析，並已補上單元分類。
- 3 組新舊題目具有相同題幹但選項不同；資料保留兩種版本，單次測驗會避免重複抽出相同題幹。
- 原有 500 題來源標示為「使用者匯入（來源待核對）」。未確認來源、年度或難度的題目，不會自動標示為官方歷屆試題。
- 目前 560 題尚未標註難度或年度。維護者可在「題庫管理」修改，但更改預設只存在於本機，需匯出 JSON 後提交才能供所有訪客使用。
- 目前沒有寫作測驗及英語聽力題目，網站只顯示實際可用的科目。

## 功能
- 依年級、科目、單元、難度、年度篩選與關鍵字搜尋。
- 一般隨機、智慧弱點抽題、錯題重練、收藏練習、待複習練習。
- 自訂題數、計時模擬考、倒數計時、時間到自動交卷、未答題號提醒及跳轉補答。
- A／B／C／D 鍵盤作答、左右方向鍵切題、未完成測驗自動保存與恢復。
- 逐題檢討、提供已匯入的解析、科目與單元正確率、最近測驗趨勢及弱點排序。
- 本機編輯題目單元、難度、年度、來源標籤、tags 與詳解；可匯出題庫 JSON。
- 完整個人備份還原、測驗紀錄 CSV、錯題清單 CSV、收藏與待複習 CSV。
- 深色模式、響應式手機排版、可安裝 PWA 與同源題庫快取。
- GitHub Actions 自動驗證題庫結構／JavaScript，並部署到 GitHub Pages。

## 本機資料與隱私
- 成績、錯題、收藏、分類修改與未完成測驗使用 `localStorage`，不會自動同步到其他裝置。
- 建議定期下載「完整個人備份 JSON」。
- PWA 離線功能需先成功載入並快取網站及題庫。

## 歷屆試題來源
官方歷屆試題請以國中教育會考官方網站為準，匯入、引用或再散布前請確認來源與使用條款：
https://cap.rcpet.edu.tw/examination.html

## 部署
GitHub Pages 由 `.github/workflows/pages.yml` 部署；題庫與功能檢查位於 `.github/workflows/quiz-validation.yml`。
