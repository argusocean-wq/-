# 會考練習室｜國中線上題庫

GitHub Pages 靜態網站，支援五科題庫、計時模擬考、錯題重練、智慧抽題、個人學習報告、題庫分類校正、匯入／匯出與 PWA 離線快取。

## 題庫狀態
- 既有題目：500 題
- 本次新增：60 題（國文、英語、數學、社會、自然各 12 題）
- 合計：560 題
- 提供解析：60 題（其他題目未提供解析時，網站不會自行編造）
- 年度及難度欄位仍未標註的題目會明確顯示為未知；需由維護者核對後再補值。
- 新增 60 題來自「會考練習題_第一批60題.zip」，其說明標示為原創會考風格練習題，並非歷屆原題。
- 既有 500 題標示為「使用者匯入（來源待核對）」，不會自動聲稱為官方題目。

## 功能
- 依實際題庫動態顯示科目、年級、單元、難度、年度。
- 關鍵字搜尋、一般隨機、智慧弱點抽題、錯題、收藏與待複習模式。
- 自訂題數、計時模擬考、時間到自動交卷、未答題號清單與跳轉補答。
- 鍵盤 A/B/C/D 作答、左右方向鍵切題、未完成測驗保存與恢復。
- 逐題檢討、詳解（若資料有提供）、單元／科目表現、最近測驗趨勢。
- 題目分類與詳解可本機編輯，並可匯出完整題庫 JSON。
- 完整備份匯入／匯出、測驗歷史 CSV、錯題 CSV、收藏／待複習 CSV。
- 深色模式、手機版排版、PWA 安裝入口、同源題庫快取離線支援。

## 部署
GitHub Pages 的 workflow 在 `.github/workflows/pages.yml`，題庫格式與 JavaScript 語法驗證在 `.github/workflows/quiz-validation.yml`。

## 隱私及限制
- 成績、錯題、收藏、分類修正與未完成測驗存在使用者瀏覽器 localStorage，不會同步到其他裝置。
- PWA 的首次離線使用需先成功載入網站與題庫。
- 瀏覽器本機修改只對該瀏覽器生效。要讓所有訪客共用修改，需匯出 JSON 並由倉庫維護者提交至 GitHub。
- 歷屆考題、年度、難度與答案需經來源核對；未核對資訊不會自動標示為官方。
