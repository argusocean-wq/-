# 會考練習室｜部署與使用說明

網站：https://argusocean-wq.github.io/-/

## 目前題庫
- 題目紀錄 560 題：既有 500 題與新增 60 題。
- 國文 112、英語 112、數學 132、社會 102、自然 102。
- 新增 60 題是原創會考風格練習題，含詳解，並非歷屆原題。
- 3 組新舊題目同科目題幹相同但選項不同，完整資料均保留；單次抽題會避免同題幹重複。
- 難度及年度均未標註的題目會顯示為未標示，不會自行推測。

## 網站功能
- 依年級、科目、單元、難度、年度篩選及關鍵字搜尋。
- 一般隨機、智慧弱點抽題、錯題、收藏與待複習模式。
- 自訂題數、計時模擬考、時間到自動交卷、未作答題號跳轉提醒。
- A/B/C/D 鍵盤作答、方向鍵切題、未完成測驗保存及恢復。
- 逐題檢討、科目與單元表現、最近成績趨勢。
- 題庫資料編輯、JSON 匯入／匯出、備份還原及多種 CSV 匯出。
- 深色模式、響應式手機介面、PWA 安裝與已快取題庫離線練習。

## GitHub Pages
部署由 `.github/workflows/pages.yml` 自動完成，題庫與程式驗證由 `.github/workflows/quiz-validation.yml` 完成。
若需要重新選擇來源，進入 Settings → Pages → Build and deployment，選擇 **GitHub Actions**。

## 個人資料
成績、錯題、收藏、題庫本機修改與未完成測驗存在目前瀏覽器的 localStorage，不會自動跨裝置同步。請定期從「資料備份」下載完整備份 JSON。
題庫維護者如要讓分類或詳解修正對所有訪客生效，請從「題庫管理」匯出完整題庫 JSON，再將修正內容提交至 GitHub 的 `data/questions.json`。
