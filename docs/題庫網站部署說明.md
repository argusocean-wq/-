# 會考練習室｜台灣國中線上題庫

這是可部署到 GitHub Pages 的純前端網站。

## 目前整合狀態
- ZIP 中 TXT 題目檔：500 個
- 成功解析：500 題
- 格式未能解析：0 個
- 題庫檔案：`data/questions.json`
- 網站入口：`index.html`

## 功能
- 年級、科目、單元篩選
- 隨機抽題，10／20／50／100 題或全部符合題目
- 單選作答、上一題／下一題、交卷與自動批改
- 錯題本與錯題重練
- 本機瀏覽器保存測驗紀錄（localStorage）
- 手機與桌面版響應式介面

## GitHub Pages 部署
1. 解壓縮本包。
2. 將 `index.html`、`data/` 與 `README.md` 放在 GitHub 倉庫根目錄。
3. 在 GitHub 倉庫進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/(root)`，按 **Save**。
6. 等待 GitHub Pages 部署完成，頁面會顯示公開網址。

## 重要說明
- 本版本不需要 API Key、伺服器或資料庫。
- 成績和錯題只存在同一瀏覽器的本機儲存空間；清除網站資料或換裝置不會同步。
- 題庫說明標示這 500 題是原創練習題，不是歷屆會考原題。
- 題庫沒有提供解析的題目，結果頁只顯示正確答案，不會自動編造解析。
- 此網站目前尚未直接推送至 GitHub；需由你將檔案上傳至正確的倉庫並啟用 Pages。
