## 尚未完成

1. 逐年確認官方頁面中的實際檔案與可用科目。
2. 依各檔案的授權／使用條款判定可否轉錄、儲存及公開再散布；未確認前保留來源連結，不複製整份題目。
3. 在允許使用的範圍內建立題目資料，包含題目、選項、正確答案、解析、科目、年度及來源。
4. 對照官方版面核對答案與圖表；未核實資料不得標記為 published。
5. 根據逐年查證結果，更新全歷屆題目匯入率及剩餘數量。

## 計算規則

- **來源登記率**：有來源紀錄的追蹤項目 ÷ 本輪追蹤項目。
- **題目內容匯入率**：已匯入且具備可用內容的題目集 ÷ 已核定範圍內的題目集。
- **正式可發布率**：已完成來源核對與權利審查的題目集 ÷ 已核定範圍內的題目集。
- 答案表轉錄、來源索引、PDF 連結及資料夾建立均不算成完整題目內容匯入。
- 每次匯入後都要更新本文件，報告已完成數、剩餘數與百分比；如分母改變，必須註明原因。
