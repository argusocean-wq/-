## 計算規則

- **來源登記率**：有來源紀錄的追蹤項目 ÷ 本輪追蹤項目。
- **題目內容匯入率**：已匯入且具備可用內容的題目集 ÷ 已核定範圍內的題目集。
- **正式可發布率**：已完成來源核對與權利審查的題目集 ÷ 已核定範圍內的題目集。
- 答案表轉錄、來源索引、PDF 連結及資料夾建立均不算成完整題目集匯入；部分題目紀錄另以實際題數追蹤。
- 每次匯入後都要更新本文件，報告已完成數、剩餘數與百分比；如分母改變，必須註明原因。

## 批次匯入驗證工具（2026-10-17）

- 新增 `scripts/validate-question-batch.mjs`，供完整來源 payload 正規化後、寫入題庫前執行。
- 檢查項目：JSON 可解析、試卷宣告題數與實際紀錄數一致、題目 ID 不重複、題號格式、題幹與狀態欄位、選擇題選項與答案 ID 一致，以及「published」紀錄必須同時具有官方答案核實與權利清除狀態。
