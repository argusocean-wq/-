# 歷屆試題匯入政策

## 官方來源

國中教育會考歷屆試題專區：<https://cap.rcpet.edu.tw/examination.html>

官方網站提供歷屆題本及參考答案供查閱。網站公開可瀏覽或下載，不等同於已授權任意複製、重新發布或商業使用。

## 匯入流程

1. 記錄官方來源網址、年度、科目、檔名與擷取日期。
2. 確認題目及答案的著作權、授權條款或可再利用依據。
3. 若權利未確認，僅保存來源連結與描述性中繼資料，不將題目原文或整份答案複製到本專案。
4. 若允許使用，再轉換為本專案的題目 JSON 格式，並進行人工校對。
5. 將題目標記為 `source_verified`、`rights_reviewed`，完成必要審查後才可 `published`。
6. 對圖片、圖表、聽力音檔與寫作題目分別確認使用權利。

## 品質檢查

- 核對題號、選項順序、正確答案與年度。
- 不猜測缺漏答案；不確定的欄位標記待審。
- 保留原始來源與版本紀錄。
- 難度分級應根據明確的教學規則或人工審查，不可冒稱官方分級。
