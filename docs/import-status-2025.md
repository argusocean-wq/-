## 狀態

1. 已建立 2025 年答案表初始轉錄與第 1–30 題 CSV。
2. 答案資料的來源是可搜尋到的答案 PDF 文字擷取；第 31 題後因 PDF 表格的空白欄位造成欄位對齊風險，仍須逐格對照 PDF 視覺版面及官方來源。
3. 各科題本、寫作題目及聽力音檔先登記來源頁面，不複製整份題目內容。
4. 此批資料不應在人工核對前直接上線作為正式答案。
